# Vendored example: encode/httpx

Trimmed snapshots of https://github.com/encode/httpx (BSD-3-Clause, see `*/LICENSE.md`), produced with
`git archive <tag> httpx docs README.md LICENSE.md` (images, CSS and theme overrides removed).
They are vendored so the evaluation is reproducible offline. `docsync` also runs directly on a live
clone (`--repo <path> --base <ref> --head <ref>`).
